# arquitectura-ms3

Microservicio 3 (Go + PostgreSQL) del proyecto de Arquitectura de Software.

## Tecnologías

- Go
- Docker
- Docker Compose

## Estructura

```
📄 Dockerfile
📄 coverage
📁 db
📄 docker-compose.yml
📄 go.mod
📄 go.sum
📁 handlers
📄 main.go
📁 models
📁 services
📁 test-client
```

## Cómo ejecutarlo

```bash
go mod download
go run .
```
